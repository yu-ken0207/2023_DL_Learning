# 2023 Deep Learning Assignments

**English** | [繁體中文](README.zh-TW.md)

Deep learning coursework from 2023, written in PyTorch: image classification, semi-supervised and self-supervised learning, transfer learning, and object detection.

| Folder | Topic |
|---|---|
| `A2/` | Binary classification and multi-class classification |
| `A3/` | Semi-supervised flower classification |
| `A4/` | Self-supervised and transfer learning on CIFAR-10 |
| `A5/` | YOLO object detection on PASCAL VOC (ResNet backbone, YOLO loss, VOC evaluation, Kaggle submission script) |

Assignment A6 (text sentiment classification with prompt learning) is not in this repository.

Through these assignments I learned to build, train, and tune neural networks, and to improve their results on specific tasks.
